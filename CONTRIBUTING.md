# 🤝 Contributing to Coding Club Quiz Automation

First of all — thanks for taking the time to contribute! Every suggestion, bug report, and improvement helps make this better for coding clubs everywhere. 🙌

---

## 🐛 Found a Bug?

1. Go to [Issues](https://github.com/vaibhav44byte/coding-club-quiz-automation/issues)
2. Click **"New Issue"**
3. Describe what happened and what you expected
4. Include any error messages from the Apps Script execution log
5. Submit!

---

## 💡 Have a Feature Idea?

1. Go to [Issues](https://github.com/vaibhav44byte/coding-club-quiz-automation/issues)
2. Click **"New Issue"**
3. Start the title with `[Feature Request]`
4. Describe your idea and why it would help

## 🔧 Want to Contribute Code?

```
1. Fork this repo
2. Make your changes
3. Test it works
4. Submit a Pull Request
```

### In detail:

**Step 1 — Fork the repo**
Click the **Fork** button at the top right of this page. This creates your own copy.

**Step 2 — Clone your fork**
```bash
git clone https://github.com/YOUR_USERNAME/coding-club-quiz-automation.git
cd coding-club-quiz-automation
```

**Step 3 — Create a branch**
```bash
git checkout -b feature/your-feature-name
```

**Step 4 — Make your changes**
Edit the files, test everything works in your own Apps Script.

**Step 5 — Commit your changes**
```bash
git add .
git commit -m "Add: description of what you changed"
```

**Step 6 — Push and open a Pull Request**
```bash
git push origin feature/your-feature-name
```
Then go to GitHub → click **"Compare & pull request"** → describe your changes → submit!

## 📝 Commit Message Style

Keep it simple and clear:

```
Add: new feature or file
Fix: bug you fixed
Update: change to existing feature
Remove: something you deleted
Docs: documentation changes only
```

Examples:
```
Add: Telegram bot integration
Fix: duplicate quiz creation on same day
Update: difficulty level to easy-medium
Docs: improve setup guide with screenshots
```

---

## ⚠️ Important Rules

- **Never commit API keys** — use placeholder text like `"gsk_YOUR_KEY_HERE"`
- **Test before submitting** — make sure your changes actually work in Apps Script
- **One feature per PR** — keeps things clean and easy to review
- **Update the README** if your change adds a new feature
